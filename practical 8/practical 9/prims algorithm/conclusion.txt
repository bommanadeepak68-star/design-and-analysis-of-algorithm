Prim's Algorithm

Conclusion: Prim's algorithm is a greedy algorithm used to find the Minimum Spanning Tree (MST) of a connected, weighted, undirected graph. It repeatedly selects the minimum-weight edge connecting a visited vertex to an unvisited vertex until all vertices are connected with minimum total cost.

Complexity (using heapq / priority queue)

Case		Time Complexity	
Best case	O(E log E)
Average case	O(E log E)	
Worst case	O(E log E)

Space Complexity O(V + E)
