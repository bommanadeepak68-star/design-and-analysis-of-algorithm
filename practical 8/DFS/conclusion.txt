DFS Complexity:
For the DFS code using an adjacency list:
Let:
 V = number of vertices
 E = number of edges
Time Complexity:
Case		Time Complexity
Best Case	O(V + E)
Average Case	O(V + E)
Worst Case	O(V + E)


DFS may visit every reachable vertex and examine every edge, so all three cases are O(V + E).

Space Complexity:
O(V)
The visited set and recursion stack can store up to V vertices.
The graph itself requires O(V + E) storage, but the additional space used by DFS is O(V).

Conclusion:
Conclusion: Depth First Search (DFS) is a graph traversal algorithm that explores a path as deeply as possible before backtracking. It uses recursion (or a stack) and a visited set to traverse the graph without repeatedly visiting vertices. For an adjacency-list representation, DFS has O(V + E) time complexity in the best, average, and worst cases and O(V) auxiliary space complexity.
